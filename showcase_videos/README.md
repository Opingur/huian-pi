# Offline competition showcase videos

Copy only the curated, pre-rendered local demonstration videos for the competition
to this directory on the Raspberry Pi. The 8780 display page discovers supported
video files automatically and plays them with the browser''s native controls.

The supported extensions are `.mp4`, `.m4v`, `.mov`, and `.webm`. These media
files are intentionally ignored by Git. They are not YOLO input files and opening
them never starts inference.
